## Scope

### 1. Booking Service (Public)

Create `apps/landing/src/services/booking.ts`:

```typescript
export const publicBookingService = {
  createHold(input: { routeId: string; slotId: string; passengerName: string; passengerCount: number; email: string; phone?: string }): Promise<{ bookingId: string; holdId: string; expiresAt: string }>
  createPreference(holdId: string): Promise<{ paymentId: string; preferenceId: string; initPoint: string; expiresAt: string }>
  getBooking(bookingId: string): Promise<BookingStatus>
}
```

Use `invokeEdgeFunction` from `@connect/core` to call:
- `create-booking-hold` — creates the hold
- `create-payment-preference` — creates MP checkout

### 2. Booking Page

Create `apps/landing/src/pages/Booking.tsx`:

Route: `/roteiro/:slug/reservar`

Steps (multi-step form):
1. **Route summary** — nome, preço, duração (read-only)
2. **Slot selection** — date/time picker (reuse availability widget)
3. **Guest info** — nome, email, telefone, passageiros
4. **Confirmation** — resumo + "Ir para pagamento" button

Each step has loading/error states.

### 3. Checkout Redirect

After hold + preference created:
- Show MP checkout link/button
- Auto-redirect (or click) to `initPoint`
- Handle redirect back to confirmation page

### 4. Confirmation Page

Create `apps/landing/src/pages/BookingConfirm.tsx`:

Route: `/reserva/:bookingId/confirmacao`

- Show booking reference
- Payment status (pending — poll via `getBooking`)
- Instructions (check email, WhatsApp contact)
- CTA "Ver status da reserva"
- Loading skeleton while polling

### 5. Booking Status Page

Create `apps/landing/src/pages/BookingStatus.tsx`:

Route: `/reserva/:bookingId`

- Show booking details (route, date, passengers, status)
- Payment status with badge
- Cancel button (with confirmation)
- Timeline of status changes

### 6. Guest Auth (minimal)

For the guest flow, use email+phone as identification:
- No password required for booking creation
- Booking lookup by email + booking ID (or simple token in URL)
- Future: OTP login (reuse from S1.1.2)

### 7. Update RouteCard + RouteDetail

- Enable "Reservar Online" button → link to `/roteiro/:slug/reservar`
- Pass selected slot/date in URL params if available

### 8. Reuse/Access @connect/core from landing

The landing app already has `@connect/core` as a dependency. Use:
- `createSupabaseClient()` for auth context
- `invokeEdgeFunction()` for EF calls
- Types from `Database`
