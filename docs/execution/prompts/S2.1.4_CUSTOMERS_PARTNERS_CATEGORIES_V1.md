### 4. Computed Stats

For computed fields (experiences_count, bookings_count, revenue_generated, total_spent, etc.), use Supabase aggregate queries in the service layer:

```typescript
// Example: bookings count for a partner
const { count } = await supabase
  .from('routes')
  .select('id', { count: 'exact', head: true })
  .eq('partner_id', partnerId)
```

These should be part of the `list` query using joins or separate count queries.
