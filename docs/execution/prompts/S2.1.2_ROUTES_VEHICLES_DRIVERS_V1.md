### Previous Pattern (follow this exactly)

From S1.3 and S1.4, the established pattern is:
1. Create service layer (`apps/web/src/services/<module>.ts`) using `@connect/core` Supabase client
2. Create React Query hooks (`apps/web/src/hooks/use<Module>.ts`) with list/getById/mutations
3. Migrate page to remove mock imports, use hooks
4. Add loading/error/empty states
5. Add tenant scoping (`.eq('tenant_id', tenantId)`)
6. Typecheck + lint + build

- `list(tenantId)` — fetch routes with route_categories join
