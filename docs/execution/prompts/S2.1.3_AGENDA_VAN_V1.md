## Scope

### 1. Extend Core Types

In `packages/core/src/types/index.ts`, add:

```typescript
type AgendaStatus = 'scheduled' | 'driver_assigned' | 'in_progress' | 'completed' | 'delayed' | 'cancelled';
type ViewMode = 'timeline' | 'grid' | 'compact';
type AgendaConflictType = 'driver_double' | 'vehicle_double' | 'time_overlap' | 'capacity_exceeded' | 'operational_delay';

interface AgendaDriverDisplay {
  id: string; name: string; initials: string; phone: string;
  vehicle_name: string; vehicle_plate: string; vehicle_type: string; vehicle_capacity: number;
}

interface AgendaTimelineEvent {
  id: string; label: string; description: string; at: string;
  color: 'teal' | 'navy' | 'amber' | 'red' | 'stone';
}

interface AgendaItem {
  id: string; reference: string; booking_type: string;
  status: AgendaStatus; scheduled_at: string; estimated_duration_min: number;
  pickup_location: string; dropoff_location: string; route_name: string | null;
  driver: AgendaDriverDisplay | null; passenger_name: string; passenger_count: number;
  notes: string | null; timeline: AgendaTimelineEvent[];
}

interface AgendaConflict {
  id: string; type: AgendaConflictType; severity: 'warning' | 'critical';
  label: string; description: string; affected_item_ids: string[];
}
```

**OR** keep types local to the agenda module if they're presentation-only. Choose the cleanest approach — if these types are only used by the agenda page, keep them in the service file. If they're reused, put them in core.

### 2. Create Agenda Service

Create `apps/web/src/services/agenda.ts`:

```typescript
export const agendaService = {
  listByDate(tenantId: string, date: string): Promise<AgendaItem[]>
  listDrivers(tenantId: string): Promise<DriverRow[]>
  detectConflicts(items: AgendaItem[]): AgendaConflict[]
}
```

`listByDate` should:
1. Query `bookingService.list()` filtered by `scheduled_at` date range
2. Map `BookingWithDetails[]` → `AgendaItem[]` using the mapping table above
3. Call `detectConflicts()` on the mapped items
4. Return items + conflicts

`detectConflicts` should:
- Find time overlaps (same driver, overlapping time windows)
- Find vehicle double-bookings
- Return typed `AgendaConflict[]`
