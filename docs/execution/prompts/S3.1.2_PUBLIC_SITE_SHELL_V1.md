## Context

- Hero + footer inline no App.tsx

- No SEO (single global meta tags)
- No Supabase connection (only .env.example)

## Scope

### 1. Install Dependencies
```bash
pnpm add react-helmet-async --filter @connect/landing
```

### 2. Create Page Structure
```
apps/landing/src/
  main.tsx          — wrap with HelmetProvider
  pages/
    Home.tsx        — hero + catalog + filtros
    NotFound.tsx     — 404
  components/
    Header.tsx      — Navbar with logo + nav links + CTA
    Footer.tsx      — full footer with links, contato, social
    RouteCard.tsx   — catalog card for route listing
    HeroSection.tsx — hero component
    CatalogSection.tsx — catalog grid with filters
    FilterBar.tsx   — category/price/duration filters
    CTASection.tsx  — call-to-action section
```

### 3. Header Component
- Logo "Dom Pietro Experience"
- Nav links: Início, Experiências, Transfers, Contato
- CTA button "Acessar App" → external link
- Mobile-responsive hamburger menu
- Sticky on scroll

### 4. Footer Component
- Company info + description
- Quick links (Início, Experiências, Transfers, Contato)
- Contact info (email, phone, WhatsApp)
- Social media links (placeholder icons)
- Copyright notice
- Responsive grid layout

### 5. Home Page (`Home.tsx`)
- `HeroSection` — headline, subtitle, CTAs (kept from current)
- `CatalogSection` — grid of RouteCards
- `FilterBar` — filter by category, price range, duration
- `CTASection` — "Fale Conosco" or "Reserve Agora"

### 6. RouteCard Component
- Route image placeholder (gradient)
- Route name, description excerpt
- Category badge
- Price display (formatted)
- Duration
- "Ver detalhes" link → `/roteiro/:slug` (future)
- Hover effect
- Loading skeleton variant
- Empty state variant

### 7. Catalog with Live Data
Create `apps/landing/src/services/routes.ts`:
```typescript
export const publicRoutesService = {
  list(filters?: RouteFilters): Promise<RouteWithCategory[]>
  getBySlug(slug: string): Promise<RouteWithCategory | null>
}
```

Create `apps/landing/src/hooks/usePublicRoutes.ts`:
- `usePublicRoutes(filters?)` — list routes with React Query
- Loading/error/empty states

Use `@connect/core` Supabase client to query `routes` + `route_categories`.

### 8. SEO
- Wrap app in `HelmetProvider` in main.tsx
- Add `Helmet` to each page with:
  - title, description
  - Open Graph tags (og:title, og:description, og:type, og:url)
  - Canonical URL
  - JSON-LD structured data (Organization) on home page

### 9. Styles
- Keep existing dark theme (slate-950 background, emerald accents)
- Use Playfair Display (display) + Inter (body) from existing config
- Ensure responsive (mobile-first)

### 10. Update Router (`App.tsx`)
- Extract pages from inline components to `pages/` directory
- Add routes for new pages
- Wrap in Layout with Header + Footer
