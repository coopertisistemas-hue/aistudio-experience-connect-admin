## Scope

### 1. Settings Service

Create `apps/web/src/services/settings.ts`:

```typescript
export const settingsService = {
  // Empresa + Operação + Branding
  getTenant(tenantId: string): Promise<TenantRow>
  updateTenant(tenantId: string, data: Partial<TenantRow>): Promise<TenantRow>
  updateSettings(tenantId: string, settings: Json): Promise<void>
  updateBranding(tenantId: string, branding: Json): Promise<void>

  // Equipe
  listTeam(tenantId: string): Promise<UserTenantWithUser[]>
  inviteMember(tenantId: string, email: string, role: string): Promise<void>
  updateMemberRole(userTenantId: string, role: string): Promise<void>
  removeMember(userTenantId: string): Promise<void>
}
```

### 2. Settings Hook

Create `apps/web/src/hooks/useSettings.ts`:

- `useTenant(tenantId)` — tenant profile + settings + branding
- `useUpdateTenant()` — mutation
- `useUpdateSettings()` — mutation  
- `useUpdateBranding()` — mutation
- `useTeam(tenantId)` — team members list
- `useInviteMember()` — mutation
- `useUpdateMemberRole()` — mutation
- `useRemoveMember()` — mutation

### 3. Migrate Settings Page

Update `apps/web/src/pages/admin/settings/page.tsx`:
- Use `useTenant()` hook instead of mock data
- Pass tenant data to child components as props
- Add loading skeleton, error state

### 4. Migrate Components (5 of 8)

**SettingsEmpresa.tsx** — Wire form to `useUpdateTenant()`:
- Replace mock `mockTenant` with tenant from hook
- Wire save button to `updateTenant` mutation
- Add loading/error on save

**SettingsOperacao.tsx** — Wire to `useUpdateSettings()`:
- Read/write `tenants.settings` jsonb
- Map form fields to settings JSON structure
- Wire save to mutation

**SettingsEquipe.tsx** — Wire to `useTeam()` + mutations:
- Replace `mockTeamMembers` with `useTeam()` list
- Wire invite button to `useInviteMember()`
- Wire role change to `useUpdateMemberRole()`
- Wire remove to `useRemoveMember()`
- Reuse existing `invite-user` edge function for invites

**SettingsPermissoes.tsx** — Compute from role:
- Permissions are derived from `user_tenants.role`
- Show matrix based on role (owner=all, admin=all except security, operator=subset)
- No DB mutations needed (role changes handled in Equipe section)

**SettingsBranding.tsx** — Wire to `useUpdateBranding()`:
- Read/write `tenants.branding` jsonb
- Wire save to mutation
