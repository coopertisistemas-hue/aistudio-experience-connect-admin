## Sprint Scope

### 1. Bookings Service Layer

Create `apps/web/src/services/bookings.ts` with typed API functions:

```typescript
// Core operations using @connect/core's invokeEdgeFunction
export const bookingService = {
  list(tenantId: string, filters?: BookingFilters): Promise<Booking[]>
  getById(id: string): Promise<Booking>
  createHold(input: CreateHoldInput): Promise<BookingHold>
  confirmFromPayment(bookingHoldId: string): Promise<Booking>
  cancel(id: string, reason?: string): Promise<void>
  reschedule(bookingId: string, newSlotId: string): Promise<Booking>
}
```

- Use `packages/core/src/supabase/client.ts` for queries
- Use `packages/core/src/edge/client.ts` for edge function invocations
- Use `packages/core/src/types/database.ts` for all types
- Apply tenant scoping via `packages/core/src/tenant/scope.ts`
- Include loading, error, and empty states
- Follow existing patterns from `packages/core/src/mutations/optimistic.ts`
