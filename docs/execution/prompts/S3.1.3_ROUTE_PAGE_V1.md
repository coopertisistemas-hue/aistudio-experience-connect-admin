## Scope

### 1. Route Detail Page

Create `apps/landing/src/pages/RouteDetail.tsx`:

- Route `/roteiro/:slug` in App.tsx
- Fetch route data via `publicRoutesService.getBySlug()`
- **Hero** — gradient background with route name and category badge
- **Info section** — description, duration, price, category
- **Gallery section** — placeholder cards (real images later)
- **Availability widget** — date picker showing available slots (from `vehicle_slots`)
- **CTAs** — "Reservar Online" and "WhatsApp" deeplink
- Loading skeleton, error state, not-found state

### 2. Extend Public Routes Service

Add to `apps/landing/src/services/routes.ts`:
- `getAvailability(routeId, date)` — query vehicle_slots for available dates/times
- Return `{ date, slots: { time, remaining_seats }[] }`

### 3. Extend usePublicRoutes Hook

Add to `apps/landing/src/hooks/usePublicRoutes.ts`:
- `usePublicRoute(slug)` — single route
- `useRouteAvailability(routeId, date)` — slot availability

### 4. WhatsApp CTA

"Reservar via WhatsApp" button with deeplink:
```
https://wa.me/5511999999999?text=Olá! Tenho interesse no roteiro {route_name}
```
Use placeholder phone (to be configured per tenant later).

### 5. Schema.org Event Markup

Add JSON-LD for `schema.org/Event` or `schema.org/Product` on route detail page.

### 6. Breadcrumbs

Add breadcrumb nav: `Início > Roteiros > {route_name}`
