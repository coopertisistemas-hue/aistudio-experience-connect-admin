# Release v0.4.0 - Frontend Foundation Stable

## Metadata
- **Release Name:** Frontend Foundation Stable
- **Release Date:** 2026-05-17
- **Version:** v0.4.0-frontend-foundation-stable
- **Status:** COMPLETE
- **Phase Readiness:** APPROVED FOR LIVE DATA INTEGRATION
- **Production Status:** NOT READY

## Summary
This release certifies the completion and stabilization of the Experience Connect frontend foundation. The project has transitioned from a multi-app structure (admin, landing, web) to a unified canonical application in `apps/web`. The UI/UX foundation, design system, and core layouts have been audited for consistency and engineering standards.

## Scope
Unification of frontend applications, implementation of the Connect Design System, setup of the tenant-aware shell, and stabilization of the monorepo for the next phase of live data integration.

## Implementation Details & Fixes
- **Unified App Architecture:** `apps/web` is now the canonical unified app.
- **Frontend Flow confirmed:** Landing → Login/Auth → Admin Panel flow validated.
- **Connect Design System:** Standardized components and styling applied across the unified app.
- **Monorepo Optimization:** `pnpm dev` now focuses on `@connect/web` by default. Legacy apps remain accessible but are not started by default.
- **Engineering Stabilization:** Kimi-led stabilization of component imports, type safety, and monorepo compatibility.
- **Audit Completion:** Codex audit verified the foundation's integrity and adherence to Connect standards.
